# Sistema de TODO List

Proyecto de gestión de tareas con prioridades, desarrollado como práctica de control de versiones con Git.

## Funcionalidades
- Agregar tareas con descripción y prioridad
- Listar tareas pendientes
- Eliminar tareas
- Marcar tareas como completadas
- Ordenar tareas por prioridad
